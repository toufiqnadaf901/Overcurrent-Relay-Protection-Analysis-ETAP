# Overcurrent Relay Protection Analysis Using ETAP ⚡

A power system protection project focused on analyzing overcurrent relay protection for different fault conditions using ETAP.

## Project Overview

This project analyzes overcurrent relay protection in a three-phase power system using ETAP. Fault current calculations, relay settings, and Time–Current Characteristic (TCC) analysis were performed to study protection coordination.

## Objectives

- Analyze fault conditions in a power system
- Calculate fault currents using ETAP
- Perform overcurrent relay protection analysis
- Optimize relay settings
- Study relay coordination using TCC curves

## Tools & Technologies

- ETAP
- Power System Analysis
- Overcurrent Protection
- Relay Coordination
- Time–Current Characteristic (TCC) Analysis

## Project Results

The project evaluated relay operation under different fault conditions and analyzed relay coordination to improve the reliability of the protection system.
